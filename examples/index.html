Lordicon React

<LordIcon>: the <lord-icon> element, with props.

  • Getting started: src, trigger, a placeholder
  • Follow React state: a toggle through aria-pressed
  • A target from a ref: a button elsewhere plays it
  • Methods and events: a ref, and onReady, onComplete
  • Icon data: the icon prop instead of src
  • A custom trigger: BaseTrigger and defineElement
  • States: fading in with :state(ready), and :state(playing)
  • A list: lazy loading, and rows that move
  • A process: follow a stage kept in React state
  • A placeholder: a still until the icon is ready
  • Looks from React state: colors, stroke, speed, currentColor
  • Intro on mount: cards from state, each icon after its card
